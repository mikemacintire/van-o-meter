Auto balance — B→A transfer automation

Enabled
Turns Unit B's AC outlets on when B reaches the start level — B's output feeds A's input, so the transfer begins immediately. Off again at the stop level, then it waits for the next fill. How hard A pulls is set by AC Charge Speed on Unit A below (200–1800 W). Manual moves are respected: flip B's AC Output off yourself and the balancer idles until the next fill.
